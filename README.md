# TV Home — своя оболочка для BBK 32LEX-7289TS2C

Минималистичный лаунчер для Android TV в духе Apple TV 4K: чёрный экран, док снизу,
сетка приложений, часы, «стеклянная» подсветка фокуса и пилюли сверху.

## Что есть

- Чёрный фон, крупные часы с тонким начертанием, приветствие и дата слева сверху.
- Стеклянные пилюли справа сверху: **Входы**, **Wi-Fi** (показывает имя сети), **Настройки**.
- Док в нижней полосе: 4 слота, приложения из `config.xml`.
- Сетка остальных приложений: 5 колонок, скроллится вниз, ТВ-приложения первыми.
- Одна переезжающая подсветка фокуса (не рамки на каждой плитке).
- Фокус: плитка чуть увеличивается, у дока имя показывается крупно над полосой,
  фон подсвечивается цветом, взятым из иконки приложения.
- Детерминированный D-pad: вверх с дока → верхняя панель, концы панели не проваливаются,
  вниз с последней строки → док.
- Запоминает последнюю плитку между запусками.
- Не держит сеть, не грузит видео, не использует блюр — рассчитано на 1 ГБ RAM.

## Конфигурация

`app/src/main/res/values/config.xml`:

| Параметр | Смысл |
|---|---|
| `columns` | колонок в сетке (сейчас 5) |
| `dock_slots` | слотов в доке, 4–7 (сейчас 4) |
| `dock_apps` | пакеты в доке по порядку; `settings` — системные настройки ТВ |
| `greeting_name` | имя для приветствия, можно оставить пустым |

Сейчас в доке: `com.yandex.tv.ytplayer` (YouTube), `mobi.zona` (Zona), `settings` (Настройки),
четвёртый слот пустой.

## Сборка

### Вариант 1 — GitHub Actions (без установки чего-либо)

1. Создайте на GitHub пустой репозиторий (можно приватный).
2. Загрузите туда содержимое папки `launcher-project` (кнопка **Add file → Upload files**;
   в Chrome можно перетащить папку целиком, структура сохранится).
3. Откройте вкладку **Actions** → workflow **build-apk** → **Run workflow**.
4. Через 2–3 минуты скачайте артефакт **tvhome-debug** — внутри `app-debug.apk`.

Workflow уже лежит в `.github/workflows/build.yml` и собирает debug-сборку на JDK 17 + Gradle 8.2.

### Вариант 2 — Android Studio

Открыть папку `launcher-project` как проект, дождаться синхронизации Gradle,
**Build → Build Bundle(s)/APK(s) → Build APK(s)**.

## Установка на телевизор

APK положить в `apk\` этого рабочего каталога — дальше я:
1. проверю пакет и `minSdk`;
2. поставлю через `adb push` + `pm install` (потоковая установка на этом ТВ падала из-за нехватки RAM);
3. назначу домашним: `cmd package set-home-activity com.custom.tvhomeshell/.MainActivity`;
4. проверю `dumpsys activity activities | grep mFocusedApp` и скриншотом;
5. сделаю одну перезагрузку и проверю, что Home и ADB вернулись.

Стоковый Яндекс-лаунчер **не отключается** (борда CVTE) — остаётся запасным.

## Известные ограничения

- Здесь нет JDK и Android SDK, поэтому код **не компилировался**. Первый прогон CI может
  выдать ошибку — пришлите лог, поправлю.
- «Входы» показывают список входов из `TvInputManager`, но переключают запуском приложения
  входа, а не полноценным `TvView`-сеансом. На этом ТВ может оказаться достаточно; если нет —
  доработаем.
- Шрифт Outfit не включён (нет возможности скачать TTF): используется системный
  `sans-serif-thin`. Файл `outfit.ttf` можно положить в `res/font/` и переключить `setTypeface`.
- Плитки без своих иконок (adaptive icons) могут выглядеть упрощённо.
